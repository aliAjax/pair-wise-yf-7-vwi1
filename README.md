# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 送印锁版闭环

- **锁版送印**：右侧「送印锁版」面板填写印数（正整数）与校对人后，方可提交锁版。
- **锁版条件**（任一不满足则整次拒绝，版面保持不变，并列出全部未满足项）：
  - 版面按阅读顺序（横排先行后列、竖排先列后行）连续无空格，允许末尾留白；
  - 所有落字用量不超过字模库存；
  - 版面未使用任何「旧痕」成色的字模；
  - 改版记录已清空；
  - 印数与校对人均已填写。
- **改版流程**：锁版后调整作品设置（纸张、方向、网格、作品名）、字模（加入、删除）或落字（点按、拖拽、清空版面、载入草稿），均须在弹窗中填写改版依据；确认后自动回到「待校对」并生成一条改版记录。
- **再次锁版**：清空全部改版记录后才能重新锁版。
- **状态同步**：锁版状态同步体现在筛选（成色筛选与字模卡标记）、用量统计、草稿列表、版面印章与导出的 PNG 预览图上。
- **数据存储**：全部数据（字模、版面、设置、草稿、锁版与改版记录）仅保存在浏览器 `localStorage`，无任何后端请求。
