# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 送印锁版闭环

- **送印信息**：锁版前需在「送印锁版」面板填写印数和校对人。
- **锁版校验**：仅当版面连续无空格（按阅读顺序从首字到末字无空格）、字模库存充足、版面不含旧痕字模时才能锁版；任一条件不满足则整次拒绝，版面保持不变，并列出全部未通过项。
- **改版流程**：锁版后调整作品设置、字模库或落字，会先要求填写改版依据；登记后自动回到「待校对」状态并留下改版记录。
- **再次锁版**：存在改版记录时无法锁版，需先清空改版记录。
- **状态同步**：字模筛选区、用量统计、草稿列表和导出预览图都会显示当前锁版状态；草稿保存时会记录当时的锁版快照，预览图会加盖「已锁版 / 待校对」印记。

所有数据（字模、版面、草稿、送印信息、锁版状态、改版记录）仅保存在浏览器 localStorage 中。
